# Room Auto-Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent user data loss on app updates by establishing Room auto-migration infrastructure.

**Architecture:** Enable schema export so Room writes versioned JSON snapshots of the DB schema. Each version bump is accompanied by an `@AutoMigration` annotation, allowing Room to generate migration SQL at build time. Version 1 schema is captured as a baseline; version 2 is a no-op bump that activates the infrastructure without changing any tables.

**Tech Stack:** Room 2.4+ Auto-Migration, KSP, JUnit4, Room MigrationTestHelper (instrumented test)

### Task 2: Write the failing migration test

**Files:**
- Create: `app/src/androidTest/java/com/wolf/musicplayer/MigrationTest.kt`

- [ ] **Step 1: Create the instrumented migration test**

  `app/src/androidTest/java/com/wolf/musicplayer/MigrationTest.kt`:
  ```kotlin
  package com.wolf.musicplayer

  import androidx.room.testing.MigrationTestHelper
  import androidx.test.ext.junit.runners.AndroidJUnit4
  import androidx.test.platform.app.InstrumentationRegistry
  import com.wolf.musicplayer.data.db.AppDatabase
  import org.junit.Assert.assertEquals
  import org.junit.Rule
  import org.junit.Test
  import org.junit.runner.RunWith

  @RunWith(AndroidJUnit4::class)
  class MigrationTest {
      @get:Rule
      val helper = MigrationTestHelper(
          InstrumentationRegistry.getInstrumentation(),
          AppDatabase::class.java,
      )

      @Test
      fun migrate1To2_preservesPlaylistData() {
          // Create a v1 database with a playlist row
          helper.createDatabase(TEST_DB, 1).apply {
              execSQL(
                  "INSERT INTO playlists (name, serverId, isLocal) VALUES ('Favorites', NULL, 1)"
              )
              close()
          }

          // Run migration from 1 → 2 and validate schema
          val db = helper.runMigrationsAndValidate(TEST_DB, 2, true)

          // Verify the playlist row survived
          val cursor = db.query("SELECT name FROM playlists WHERE name = 'Favorites'")
          assertEquals(1, cursor.count)
          cursor.close()
      }

      companion object {
          private const val TEST_DB = "migration-test"
      }
  }
  ```

- [ ] **Step 2: Run the test — expect FAIL because version 2 doesn't exist yet**

  Connect a device or start an emulator, then:
  ```bash
  ./gradlew connectedAndroidTest --tests "com.wolf.musicplayer.MigrationTest"
  ```

  Expected: FAIL — Room throws because `AppDatabase` is still at version 1 and the test asks to migrate to version 2.

  ```kotlin
  package com.wolf.musicplayer.data.db

  import androidx.room.AutoMigration
  import androidx.room.Database
  import androidx.room.RoomDatabase
  import com.wolf.musicplayer.data.db.dao.PlayWeightDao
  import com.wolf.musicplayer.data.db.dao.PlaylistDao
  import com.wolf.musicplayer.data.db.dao.SongDao
  import com.wolf.musicplayer.data.db.entity.PlayWeightEntity
  import com.wolf.musicplayer.data.db.entity.PlaylistEntity
  import com.wolf.musicplayer.data.db.entity.PlaylistSongEntity
  import com.wolf.musicplayer.data.db.entity.ServerEntity
  import com.wolf.musicplayer.data.db.entity.SongEntity

  @Database(
      entities = [
          SongEntity::class,
          PlayWeightEntity::class,
          PlaylistEntity::class,
          PlaylistSongEntity::class,
          ServerEntity::class,

      exportSchema = true,
      autoMigrations = [
          AutoMigration(from = 1, to = 2),
      ],
  )
  abstract class AppDatabase : RoomDatabase() {
      abstract fun songDao(): SongDao
      abstract fun playWeightDao(): PlayWeightDao
      abstract fun playlistDao(): PlaylistDao

  ```

## Future Schema Change Workflow

For every future schema change (e.g., adding a column, adding a table):

1. Modify the entity
2. Increment `version` by 1 in `@Database`
3. Add `AutoMigration(from = N, to = N+1)` to the `autoMigrations` list
4. Run `./gradlew assembleDebug` — Room writes `N+1.json` and validates
5. Add a test case in `MigrationTest.kt` for the new migration
6. Commit all changed files including the new schema JSON

**For column renames or complex transforms**, implement `AutoMigrationSpec`:
```kotlin
@DeleteColumn(tableName = "songs", columnName = "oldColumn")
class MySpec : AutoMigrationSpec

// Then reference it:
AutoMigration(from = 2, to = 3, spec = MySpec::class)
```
